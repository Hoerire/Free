<h1 align="center">ColorOS 小窗（Free）</h1>

  <img src="https://img.shields.io/badge/ROM-ColorOS-00A862" alt="面向 ColorOS" />
  <img src="https://img.shields.io/badge/Android-15%2B-3DDC84?logo=android" alt="最低 Android 15" />

**Free 给 ColorOS 带来一套全新的交互：把魅族的 Flyme 小窗玩法搬了过来。** 从屏幕底角斜向内上滑，扇形菜单顺着指尖铺开，滑到目标松手，应用当即以自由浮窗落在屏幕上。

这是一个 LSPosed 模块，不改动系统分区：窗口、动效与模糊都走 ColorOS 自己的链路，所以看起来、用起来都像系统自带；设置改完即时生效，不需要重启框架。改动记录见 [CHANGELOG.md](CHANGELOG.md)，版本号以仓库的 Release 为准。

## 扇形菜单

底角是这套交互的起点。菜单从角落铺开，最多七格：应用、分身、侧边栏工具与快捷入口可以混排，长按拖动排序；还能再配一组，让左右两侧显示不同的内容。

- **呼出**：底角斜向内上滑，可选左右、仅左、仅右；桌面上的底角上滑不再被拿去拉起多任务
- **保持挂起**：松手后不收起，可以继续滑动点选
- **范围与大小**：触发范围 24–160 dp、命中范围 40–220 dp、图标 32–56 dp，拖动滑条时屏幕上有实时示意图
- **按窗口状态分流**：全屏应用原地变成小窗，已打开的小窗收成迷你窗，迷你窗恢复成小窗，贴边浮标保持原样
- **暂停**：横屏与游戏模式只暂停呼出，退出后自动恢复；还可开启「屏蔽键盘」，键盘弹出时也不呼出

## 小窗与贴边

小窗在这里是一套完整的状态机，而不是简单的「缩小版全屏」。

- **关闭小窗**：轻击窗外、双击窗外，或轻点窗口底部横条
- **小窗数量**：并发上限 1–12（在 **设置 → 小窗交互** 里调）；迷你窗不计入这个数量，可以和一个小窗同时存在
- **自动收窗**：超出数量时只关最旧的普通小窗，迷你窗不参与裁决、始终保留
- **快速上滑**：底部横条上滑切为迷你形态
- **边缘拖动**（小窗交互 → 手势交互 → 边缘拖动）：默认只有下拉窗口底部会变全屏；打开后把窗口左右边向外拉一点、松手就变全屏
- **横条沉浸**：全面屏手势指示条与小窗的底部横条、顶部三点平时隐藏，**触摸时出现、松手即收回**；与官方开关不同，**不占位、应用不下沉**，布局与内容位置始终不变
- **隐藏卡片**：小窗应用的多任务卡片不再出现在最近任务里，应用本身照常运行
- **自动贴边**：选中的应用**全屏**时**上滑返回桌面**，自动收成贴边浮标继续跑；已经是小窗/迷你/贴边的不接管（拖到边缘就能自己收）。名单在 **设置 → 小窗交互 → 自动贴边**
- **解除限制**：原本不支持自由浮窗的应用也能开
- **禁用浮窗**：列表内的应用，拉起别人、被别人拉起都不改写
- **轻量打开**：按场景决定是否小窗——通知中心、通知横幅、控制中心、应用跳转、复制链接（登录授权与分享交给官方处理）
- **通话保持全屏**：来电（含微信等第三方 VoIP）与拨号打开的通话界面不会被收进小窗，接听与拨号都走系统原本的全屏界面

**贴边挂机**：窗口收成浮标后，应用不进入暂停，继续按前台状态运行——游戏继续渲染、挂机、下载更新都不中断；期间还会拿到系统后台豁免，锁屏后新建的网络请求不会被限。它只对浮标里的任务生效，关掉开关即恢复原状；同时保留的浮标个数可调，最多 12 个。代价是浮标里的应用持续占用 CPU 与 GPU，耗电和发热会上升。

**小窗交互页**：小窗开关与启动场景、小窗数量、小窗位置、隐藏卡片、手势交互（上滑转迷你 / 边缘拖动 / 长按静音 / 点窗外关闭）、贴边挂机与自动贴边都在 **设置 → 小窗交互**；整页（除总闸那一行）受「启用交互」总闸控制，关掉后界面项与行为一起停用。

**长按静音**：在小窗、迷你窗上长按约 0.5 秒，只把当前窗口所属的那个应用静音，再长按恢复。判定要求按下位置落在当前浮动窗口的可见区域内、位移不超过 40px，正常拖动与缩放不会误触发。

## 侧滑扩展

边缘内滑（系统返回手势）后**不松手、继续上滑或下拉**，超过「滑动距离」（16–200 dp，默认 100）就按方向执行动作，不必等松手：

- **关闭**（默认）：不做任何接管，边缘内滑始终是原厂返回
- **小窗**：全屏应用原地变成小窗；已打开的小窗变回全屏。迷你窗与贴边浮标不在焦点上，不参与这一项——点一下它们会先变回小窗
- **更多**：直接打开「更多」面板，从屏幕哪一侧起手就用哪一组扇形内容

**下拉**要求接近竖直：整段行程和最近一小段的方向都必须落在竖直 **±20°** 以内，斜滑不触发，避免内滑之后随手一斜就误开「更多」。上滑不受角度限制。没滑够距离就松手走原厂返回，手势事件一个字节都不改写；触发之后这次返回手势会被结束，松手不会再返回。

## 通知：小窗与气泡

同样一条通知，可以进小窗，也可以变成一颗气泡。

**通知小窗**：通知中心、通知横幅、控制中心三处点开都可以自由浮窗呈现，三个场景各有独立开关；点击横幅后横幅自动收起。

**气泡通知**：白名单应用的通知变成一颗可拖动的圆形气泡，点开直接进应用，同时接管系统横幅。

- **内容浮层**：气泡旁显示应用、标题与正文，停留时长随文字长度自动调整；也可只在贴边时显示
- **队列与展开**：多条通知依次排队，上滑或长按展开一排，点哪条开哪条
- **拖动与贴边**：拖到任意位置，松手贴边半隐藏；横竖屏分别记住落点
- **到点处理**：停留时间到后可贴边收起、原地变暗留置，或直接消失，三种方式任选
- **分身**：分身应用的通知独立成键，点气泡直接进对应实例，不弹「选择打开的应用」，连具体聊天页也能直接落进去
- **状态栏滚动**：最新通知以「应用 · 标题 正文」在状态栏时钟位置**整行横向滚动**，长文本不再分页翻页；速度可在设置里调，短文本不滚、静态停留（开关与参数在 **设置 → 系统增强**）
- **过滤列表**：不想让它挡视线的应用可以单独加进来，它的通知不再进状态栏滚动，其它应用照常滚；主应用与分身分开列
- **通话通知不接管**：通话类通知不进气泡、不参与状态栏滚动、也不会被模块压掉横幅，接听入口保持系统原样。来电与拨号的通话界面也不会被收进小窗（见上一节）
- **即时建议**：手电筒、耳机音乐、新装应用、剪贴板识别（电话 / 链接 / 地址 / 快递）与保持常亮（屏幕将要变暗时点一下，钉住屏幕直到锁屏或息屏），默认关闭，全部在本机完成
- **免打扰**：当前正在用的应用、游戏模式、锁屏与息屏都可以不出气泡，三项各自独立

气泡的外观、停留时长（含到点处理方式）、浮层与白名单都在 **设置 → 系统增强 → 气泡通知** 里，改完即时生效；下面的滚动通知就在同一页旁边。

> 气泡通知目前只适配 **ColorOS 17**，其他系统（含 ColorOS 15 / 16）不保证有效果。

## 「更多」面板与解除限制

扇形末尾的「更多」取自智能侧边栏的「全部」：收藏、最近与名称搜索都在，呼出扇形时自动收起。
「最近」按**应用 + 用户**区分，分身应用会带着角标单独出现，点开进对应实例；收藏区里已有的应用不会在「最近」里重复出现。

**隐藏应用**（设置 → 系统增强）：选中的应用不再出现在面板的收藏、最近与全部列表里。只影响面板展示，不改侧边栏自己的配置。

快捷方式与工具类入口（付款码、扫一扫、识屏、屏幕翻译这类）保持原样启动、不进小窗；识屏与屏幕翻译需要系统代启动，这条链路模块已经接好。


**内容拖拽**（在 **设置 → 系统增强 → 内容拖拽** 里选应用）：选中的应用解除官方的拖拽白名单限制，任意页面都能长按拖起文字或图片；没选中的应用保持原厂规则。默认不启用——全局补白名单会让部分机型的部分应用在启动时异常，按应用开启既够用又不会波及无关应用。

## 外观与手感

参数按用途分成两类：判定类的「触发范围」「命中范围」在一级页面相邻的位置；尺寸、背景、时长与选中特效收进「外观细节」——调外观只去一处。

- **图标大小** 32–56 dp、**扇形大小** 70–140%，拖动时页顶的示意图跟着变
- **背景**：压暗与模糊合并为一条滑条，向左压暗、向右系统实时模糊（最高 100 dp），居中即不处理。模糊由系统合成，不是自绘的磨砂；它会跟着菜单一起渐变，淡入铺满展开时长、淡出铺满收回时长，选中应用时随即让开，不糊住刚出现的小窗
- **选中特效**：流光、呼吸、选中放大、选中外顶，各自可开关与调节幅度
- **动画时长**：展开、收回各可设 100–1000 ms，默认 380 / 500。图标飞出的快慢、背景压暗与模糊的渐变都跟着这两个值走；同时跟随系统的「动画时长缩放」，动画被系统关掉时直接跳到终态

浮层按 165Hz 申请刷新率，扇形铺开、流光扫过与选中反馈都是逐帧动画。

## 排除列表与其它

- **系统增强**：气泡通知、滚动通知、横条沉浸、内容拖拽、隐藏应用、侧滑扩展集中在 **设置 → 系统增强**
- **小窗交互**：小窗开关与场景、小窗数量、小窗位置、隐藏卡片、手势交互、贴边挂机与自动贴边都在这里；整页行为受「启用交互」总闸控制，关掉即整条停用（详见上一节）
- **排除列表**：列表内的应用在前台时，模块全部功能停用，离开自动恢复
- **锁屏与息屏**：停止响应，解锁后恢复
- **详细日志**：按需开启，用于反馈问题

## 安装

1. 装好并启用 **LSPosed**（需支持 libxposed API 102）
2. 安装本模块，勾选四项必需作用域：**系统框架**、**系统界面**、**桌面**、**智能侧边栏**；另外把**多窗口**（`com.oplus.pscanvas`）也勾上，系统设置里的隐藏入口由它承载
3. 从旧版本升级的，记得把**内容传送门**从作用域里取消勾选——新版本不再向该进程挂钩子
4. 重启上述进程或重启设备
5. 打开 **Free**，确认框架已连接，再按需调整

## 已知限制

- 依赖厂商私有的自由浮窗与侧边栏接口：主力支持 ColorOS 17；ColorOS 15 / 16 保留兼容，但新功能（如迷你窗不占额度、扇形窗口分流）不保证生效
- 气泡通知目前只适配 ColorOS 17，其他系统（含 ColorOS 15 / 16）不保证有效果
- ColorOS 15 / 16 的角区手势走系统指针旁听（不抢流）：扇形可正常呼出，但**防穿透无效**——触发范围内的左滑仍会穿透到下层应用
- 需要回传结果的跨应用启动（登录、授权、选图、分享回传）与分享流程交给官方处理，模块不改写
- 内容拖拽仍取不到自绘界面（Compose 等）与独立窗口里的网页；图片必须能从 ImageView 取到，否则会被静默丢弃
- 迷你窗恢复成普通小窗时不会自动收掉已有小窗（系统的数量裁决只在新增窗口时触发），此时两个普通小窗会叠在一起
